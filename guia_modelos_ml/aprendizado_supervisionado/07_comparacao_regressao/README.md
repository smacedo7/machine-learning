# Comparação de modelos de regressão

Compara famílias com a mesma base, divisão, preparação, folds e métrica. Escolhe o candidato pela validação antes de consultar o teste. A grade é pequena para estudo: a conclusão vale somente para estes dados e candidatos, e não é um ranking universal.

Abra `exemplo.ipynb` e execute as células na ordem. O notebook é independente e contém os dados de exemplo, explicações, gráficos, treinamento e interpretação. Consulte o README geral para configurar o ambiente.
