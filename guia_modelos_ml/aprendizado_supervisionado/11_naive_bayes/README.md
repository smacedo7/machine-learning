# Naive Bayes gaussiano

Aplica Bayes supondo independência condicional e distribuição gaussiana por atributo. É rápido; one-hot é uma simplificação didática aqui. Para contagem de palavras, estude MultinomialNB com TF-IDF/contagens dentro do pipeline.

Abra `exemplo.ipynb` e execute as células na ordem. O notebook é independente e contém os dados de exemplo, explicações, gráficos, treinamento e interpretação. Consulte o README geral para configurar o ambiente.
