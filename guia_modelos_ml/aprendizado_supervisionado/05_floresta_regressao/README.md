# Random Forest — regressão

Combina árvores treinadas com aleatoriedade para reduzir variância. Funciona bem em tabelas, mas é menos interpretável e não extrapola bem além do treino.

Abra `exemplo.ipynb` e execute as células na ordem. O notebook é independente e contém os dados de exemplo, explicações, gráficos, treinamento e interpretação. Consulte o README geral para configurar o ambiente.
