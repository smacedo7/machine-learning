# Máquina de vetores de suporte (SVM)

Busca uma fronteira com margem. O kernel RBF permite curvas; C controla penalização de erros e gamma a influência local. Usa decision_function para ranquear, sem confundir escore com probabilidade.

Abra `exemplo.ipynb` e execute as células na ordem. O notebook é independente e contém os dados de exemplo, explicações, gráficos, treinamento e interpretação. Consulte o README geral para configurar o ambiente.
