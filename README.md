# Machine Learning Studies 

This repository documents my Machine Learning learning journey through notes, exercises, experiments, and practical projects.

The goal is to build a strong foundation by understanding how algorithms work, how data should be prepared, and how to evaluate models correctly.

## Goals

- Understand the fundamentals of Machine Learning
- Explore, clean, and prepare datasets
- Implement regression, classification, and clustering algorithms
- Evaluate models using appropriate metrics
- Apply theoretical concepts to practical problems
- Document key concepts and lessons learned

## Learning Roadmap

- **Fundamentals:** supervised and unsupervised learning, features, and target variables
- **Data preparation:** exploratory data analysis, missing values, categorical variables, and feature scaling
- **Modeling:** regression, classification, and clustering
- **Evaluation:** train-test split, cross-validation, performance metrics, underfitting, and overfitting
- **Practice:** exercises and projects using real-world datasets

## Repository Structure

The repository will be updated as I progress through my studies. Each project or exercise will aim to include:

- A clear problem description
- The dataset and its main characteristics
- The approach and algorithms used
- Model evaluation and results
- Key lessons learned
